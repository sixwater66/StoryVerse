# StoryVerse 双端架构

采用 HashRouter；下表为应用内路由，Pages 地址在 `#/` 后接路径。尾部斜杠兼容。

| 路由 | 页面 | 职责与边界 |
|---|---|---|
| /creator | C1 创作首页与作品管理 | 新骨架，唯一作品入口；不新增/删除作品 |
| /creator/story/ | C2 故事导入与结构解析 | 复用 Studio 手稿、角色与世界设定；文件导入、自动解析待实现 |
| /creator/media/ | C3 视听素材与分镜编辑 | 新骨架；不编辑素材、分镜 |
| /creator/interactions/ | C4 交互节点与创作权限设计 | 新骨架；不修改节点或权限 |
| /creator/review/ | C5 作者审核与发布 | 新骨架；不执行审核或发布 |
| / | V1 作品发现与推荐 | 新骨架、唯一作品导航；无推荐算法；收藏入口 ?shelf=favorites 为明确标注的占位 |
| /story/ | V2 作品详情 | 复用 Work，展示原作、角色、世界与放映入口 |
| /watch/ | V3 漫剧自动播放 | 原有 Player 移至独立 Watch 页，保留进度与视频导入 |
| /explore/ | V4 场景探索与多视角 | 复用 Explore；结束后回 /watch 恢复进度 |
| /remix/ | V5 平行故事与版本展示 | 复用 Branches；独立保存，不覆盖原作 |

旧 /studio → /creator/story、/work → /story、/branches → /remix 保留重定向；未知路径回发现页。既有 Layout.tsx 保留但不再挂载。

## 布局及视觉

CreatorLayout 只负责创作者导航、当前作品、制作阶段和本地保存方式说明；保存失败仍由原有 store 提示，不伪造网络同步状态。
ViewerLayout 提供发现、详情、播放、探索、二创、收藏占位、继续体验及创作者入口。没有身份认证或权限隔离，双端为原型导航区分。

共享 UI 位于 components/ui.tsx：按钮、导航按钮、卡片、标签、字段、原生 dialog 弹窗、页面骨架。沿用原页面的 CSS 类及语义控件，避免重写已有业务表单。新骨架使用 Tailwind 支持下的共享样式；styles.css 定义深棕黑、暖米白、黄铜金、雾灰蓝变量，两端共用。桌面优先，1440 与 1920 使用流式布局；窄屏保留原响应式规则。弹窗组件供未来业务使用，本轮不添加无用途弹窗入口。

## 数据约定

src/data/types.ts + story.json + index.ts 仍为唯一预设数据契约；不改故事事实、知识边界、线索与分支。localStorage 的 storyverse-v1 键和结构不变，跨两端共享手稿与体验状态。无后端、无真实 AI、无应用内发布。新页面不新增业务状态或假成功反馈。

## 测试要求

- 每个路由可独立挂载，展示唯一页面标题及正确布局；尾斜杠可访问。
- 旧路由重定向、双端切换、详情到放映、探索返回正确。
- 继续运行旧交互与数据测试：角色知识、统一线索、分支独立保存、localStorage 恢复。
- npm run typecheck、npm run build、npm test 必须通过。
- 后续真实浏览器验收：1440×900、1920×1080 布局与滚动，HashRouter 刷新、视频策略、弹窗焦点与键盘体验。本轮 DOM 测试不替代浏览器视觉验收。

## C1 / C2 实现更新

C1 已从骨架升级为作品库：创建空白或文本作品、类型、模板提示、状态筛选、最近编辑排序、重命名、独立复制、归档/恢复、删除前确认及制作阶段跳转。示例原作、已发布作品和有正式历史的作品不能删除。复制只复制草稿与静态结构，新建 ID、清空发布历史。模板不含《旧书店的来信》人物或剧情。

C2 复用并扩展 Studio：支持粘贴、构思、UTF-8 TXT（2 MB 上限），手动编辑人物、身份/性格/目标/边界、静态关系、场景、事件顺序、世界书/规则、事实、节点与已知信息。明确标注的预设解析只接受测试故事原文；其他文本拒绝套用，可手动编辑或确认替换为示例。人物、事实、节点删除时清理引用。保存草稿允许逐步补全，进入 C3 前检查必填项、事件顺序与人物节点知识覆盖。C2 不编辑信任度、任务进度、视听时间轴或热点触发规则。

创作者导航通过 `?work=<稳定作品ID>` 保留作品上下文，未提供参数时恢复最近选择；C3/C4 增加返回 C2 的入口。C3/C4/C5 仍未新增其业务功能。编辑稿和结构不会自动覆盖观众端正式快照。

视觉变量已改为 #0D101D、#171B30、#252B47、#50E8F2、#34626D、#F4F6FF、#929BB5、#39415F。故事 SVG 素材保留，配色替换针对应用界面。
